# 脚本目录

- `userscript/学习通脚本.js`：安装到 Tampermonkey 的正式用户脚本，显示名称为 `Chaoxing Toolkit Next｜学习通辅助与本地题库`。
- `launcher/`：完成首次安装后的本地启动和停止辅助工具。
- `generate_config_contract.py`：根据配置 schema 更新各模块共享的生成内容。

首次使用请从 [安装、启动与排障](../docs/guides/quick-start.md) 开始。启动器不会自动完成前端构建，浏览器自动打开还受本机安装路径和配置影响；可选用法及限制见 [启动器说明](../docs/guides/README_STARTUP.md)。

参考脚本和历史版本不是正式维护入口。升级脚本前备份配置，避免同时启用多个版本；个人密钥与配置不提交到仓库。
