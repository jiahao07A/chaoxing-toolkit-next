## 架构与历史资料

- [`adr/`](adr/)：架构决策，入口为 [项目目录与模块边界](adr/0001-project-layout.md)。
- [`architecture/`](architecture/)：历史插件迁移方案，当前维护入口以根目录说明为准。
- [`research/`](research/)：视频与阅读任务的研究记录，不表示平台长期兼容承诺。
- [`releases/`](releases/)：历史版本变更及实验记录，不代表最新默认配置、依赖版本或部署状态。
- [`assets/`](assets/)：历史项目截图；旧登录页及旧脚本界面不作为当前界面的保证。
- [`agents/`](agents/)：自动化协作工具的项目约定，一般用户无需阅读。
