# ADR 0001：按职责整理项目目录

- 状态：已接受
- 日期：2026-09-24

## 背景

根目录同时放置用户脚本、多个启动器、截图、部署文档和题库服务文件，查找入口困难，也容易把运行时文件误提交。

## 决策

将用户脚本、启动器、文档和截图分别归档到 `scripts/`、`docs/`；保留 `tiku/` 作为服务边界，并把题库种子数据放入 `tiku/data/`。服务端使用基于自身目录的路径，启动器从脚本所在位置定位仓库根目录。

## 结果

新成员从根 README 进入即可找到使用指南和代码边界；运行时数据库、配置、缓存和虚拟环境继续留在本机并由 `.gitignore` 排除。
