# Domain Documentation

This is a single-context repository.

## Layout

- `CONTEXT.md` at the repository root describes the current domain model and module boundaries when one is present.
- `docs/adr/` contains architecture decision records.
- Read `CONTEXT.md` before making cross-module changes.
- Read relevant records under `docs/adr/` before changing a documented architectural decision.

The repository currently has no `CONTEXT.md` or ADRs; add them when the domain model or an architectural decision becomes important enough to preserve.
