# Issue Tracker

## Provider

GitHub Issues。

## Repository

Issues are tracked in the GitHub repository that contains this project. Use `gh issue` for issue operations after confirming the active remote.

## Workflow

- Issues are the primary place for bug reports, feature requests, and decisions that need a durable record.
- Pull requests are not treated as triage requests by default.
- Do not include API keys, tokens, cookies, database files, or other runtime secrets in issues.
