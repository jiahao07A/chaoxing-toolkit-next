# 人工测试清单

## 启动与页面

1. 从仓库根目录运行 `scripts/launcher/start-simple.bat`，确认服务窗口启动且浏览器打开管理页。
2. 访问 `http://localhost:8002/`、`/questions`、`/pending` 和 `/settings`，确认页面能正常加载。
3. 运行 `scripts/launcher/stop.bat`，确认端口释放；再次启动后页面仍可访问。

## 题库管理

1. 在题目页搜索一个已知题目，确认能看到答案。
2. 新增或编辑一条题目，刷新页面确认内容保留。
3. 提交一个不存在的题目，确认它出现在待处理列表；补充答案后再次查询。

## 安全导入与备份

1. 记录题库和待处理题目数量，选择 JSON 文件后确认预检阶段两项数量均未改变。
2. 导入含缺少字段、重复题目不同答案或与现有答案冲突的文件，确认问题显示行号且提交按钮不可用。
3. 导入无冲突文件，确认提交结果显示新增/跳过数量，待处理题目数量不变。
4. 连续提交 6 次导入，确认备份列表只保留最近 5 份，且每份显示时间、题目数和校验摘要。
5. 新增一条题目后恢复较早备份，确认题库回到备份状态、待处理队列保持不变；损坏备份文件时确认恢复失败且题库不变。

## 配置同步

1. 在 `/settings` 修改一个非密钥选项并保存，刷新页面确认值保留。
2. 在 Tampermonkey 设置中打开脚本配置，确认同一选项与服务端页面一致。
3. 修改题库统一开关和单个题库开关，确认脚本日志反映实际启用状态。
4. 修改日志总开关、级别和分类开关，确认日志数量和内容随设置变化。

## AI 回退

1. 暂时关闭所有题库，提交一个题目，确认会进入 AI 回退流程。
2. 使用题库未命中的题目，确认日志明确显示题库未命中、AI 请求和最终答案状态。
3. 关闭 AI 后重复测试，确认不会发起 AI 请求，并保留可处理的未命中结果。

## 视频诊断实验

1. 在脚本配置中打开“记录本地视频诊断”，播放一个短视频，确认播放器控制、任务完成判断和页面进度表现不变。
2. 在页面右下角打开“视频诊断”面板，确认记录数量只随播放、暂停、等待、速率变化和结束等播放器事件增加。
3. 导出 JSON 后检查文件只包含时间戳、事件类型和播放器状态字段，不包含课程 URL、查询参数、账号、密钥、题干或网络响应。
4. 等待或模拟超过 7 天的记录后再次打开面板，确认过期记录自动清理；点击“清理”并确认后，面板数量归零。
5. 在浏览器 Network 面板确认诊断功能没有新增进度、心跳或其他请求；关闭诊断开关后播放不再写入本地记录。

## 视频后台播放保护（P0 回归验收）

1. 打开一个未完成的视频任务，确认视频开始播放后切换到后台标签页，等待至少 10 秒再返回，播放仍会继续或自动恢复。
2. 在视频播放期间通过播放器控制或页面行为触发一次暂停，确认脚本会自动恢复播放；随机暂停期间应允许脚本按设定时长暂停。
3. 确认视频自然结束或任务状态完成后，脚本停止恢复播放，并恢复播放器原本的 `pause()` 行为。
4. 在浏览器控制台确认没有 `ReferenceError: config is not defined`，视频任务不会因随机暂停配置读取失败而提前中止。
