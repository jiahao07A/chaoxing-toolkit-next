# 本地安装完成后的检查

每位使用者都需要自行完成安装，仓库中的文档不代表你的机器已部署服务。完整安装步骤见 [安装、启动与排障](quick-start.md)。

安装完成后核对：

1. `http://localhost:8002/api/health` 返回正常服务、数据库和配置状态。
2. `http://localhost:8002/` 显示当前管理界面，无需登录。
3. Tampermonkey 中只启用一个正式脚本，题库地址及开关已按需设置。
4. 个人数据、密钥和浏览器配置留在本机，未加入 Git。
5. 退出时服务已停止，升级前已备份实际运行数据。

详细功能验收见 [人工测试清单](manual-testing.md)。没有预置的学习通账号，也不承诺种子题库覆盖全部课程。
