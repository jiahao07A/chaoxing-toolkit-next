Chaoxing Toolkit Next — 快速参考

完整安装、启动和排障步骤：docs/guides/quick-start.md
首次使用须安装后端依赖，并在 tiku/frontend 执行 npm ci 和 npm run build。

安装完成后，在仓库根目录的 Windows PowerShell 执行：
  .\tiku\venv\Scripts\python.exe .\tiku\main.py
macOS/Linux：
  tiku/venv/bin/python tiku/main.py

管理界面：http://localhost:8002/
健康检查：http://localhost:8002/api/health
题库查询地址：http://localhost:8002/api/search
正式用户脚本：scripts/userscript/学习通脚本.js

推荐在服务终端按 Ctrl+C 停止。
可选启动器用法与限制：docs/guides/README_STARTUP.md
管理台没有身份认证，只适合本机运行。
API 密钥、个人数据库和配置不提交到仓库，不发到公开 Issues。
