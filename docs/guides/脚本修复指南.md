# 脚本加载问题处理

当前脚本的加载、CDN 依赖、权限和页面排障统一见 [用户脚本排障](脚本界面问题排查.md)。正式文件只有 [`scripts/userscript/学习通脚本.js`](../../scripts/userscript/学习通脚本.js)。

修改依赖来源前先核对加载失败的 URL。保持现有版本、依赖顺序和完整头部，避免粘贴过时的整段脚本头部。需要升级时按 [安装与升级步骤](quick-start.md#用户脚本安装与升级) 操作，先备份配置并停用重复版本。

问题反馈使用 [本仓库 Issues](https://github.com/jiahao07A/chaoxing-toolkit-next/issues)，请提供脱敏的错误与复现信息。
