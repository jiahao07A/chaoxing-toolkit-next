# 快速启动指南

首次使用请按 [安装、启动与排障](quick-start.md) 完成用户脚本安装，以及可选题库服务的依赖安装和前端构建。该指南同时提供 Windows 和 macOS/Linux 命令。

后续启动、浏览器配置与停止方式见 [启动器使用说明](README_STARTUP.md)。服务默认只接受本机访问，管理台无需登录，没有完整的身份认证。

当前项目和问题反馈入口是 [jiahao07A/chaoxing-toolkit-next](https://github.com/jiahao07A/chaoxing-toolkit-next)。此文档不包含默认登录账号，也不保证固定题库数量。
