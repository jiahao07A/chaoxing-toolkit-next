# 超星学习通自动化系统 - 快速启动指南

## 一键启动（推荐）

**双击运行：** `scripts/launcher/start-simple.bat`

## 启动后会自动完成

1. ✅ 启动题库服务器（端口 8002）
2. ✅ 打开 Chrome 浏览器（Profile 4 工作区）
3. ✅ 打开仅供本机访问的题库管理界面（无需登录）
4. ✅ 自动打开学习通页面

## 服务地址

- **题库管理界面**：http://localhost:8002
- **API 接口地址**：http://localhost:8002/api/search
- **学习通页面**：https://i.chaoxing.com/base

## 本机安全

管理台不提供认证授权，服务默认绑定 `127.0.0.1`。健康检查：`http://localhost:8002/api/health`。
默认 CORS 只允许本机来源。开发跨域时可在 PowerShell 启动前设置 `$env:CORS_ORIGINS='http://localhost:5173,http://127.0.0.1:5173'`。

## Tampermonkey 配置步骤

1. 安装 Tampermonkey 扩展：https://www.tampermonkey.net/
2. 打开 `scripts/userscript/学习通脚本.js` 文件，复制内容
3. 在 Tampermonkey 中创建新脚本，粘贴并保存
4. 打开脚本设置面板
5. 启用"自定义题库"
6. 填入题库地址：`http://localhost:8002/api/search`

## 停止服务器

**双击运行：** `scripts/launcher/stop.bat`

## 使用流程

1. 双击 `scripts/launcher/start-simple.bat` 启动系统
2. 等待 Chrome 自动打开（会打开两个窗口）
3. 在学习通页面做题，脚本会自动查询题库
4. 完成后双击 `scripts/launcher/stop.bat` 停止服务器

## 常见问题

### Q1: 服务器启动失败怎么办？

**解决方法**：
1. 确认虚拟环境已创建：`tiku\venv\Scripts\python.exe` 是否存在
2. 手动启动查看错误信息：
   ```
   cd tiku
   venv\Scripts\python.exe main.py
   ```

### Q2: Chrome 打开了错误的工作区？

**解决方法**：
1. 打开 Chrome，访问：`chrome://version/`
2. 查看"个人资料路径"，找到正确的 Profile 名称
3. 修改 `scripts/launcher/start-simple.bat` 中的 `CHROME_PROFILE` 变量
4. 重新运行启动脚本

### Q3: 端口 8002 被占用？

**解决方法**：
1. 先运行 `scripts/launcher/stop.bat` 停止之前的服务器
2. 或者修改 `scripts/launcher/start-simple.bat` 中的 `TIKU_PORT` 为其他端口

### Q4: 管理台显示旧登录页或页面异常？

**解决方法**：重新构建前端并重启服务。

## 注意事项

1. **首次使用**前确保已完成部署（虚拟环境、依赖安装、前端构建）
2. **服务器在后台运行**，关闭命令行窗口不会停止服务
3. **必须使用 scripts/launcher/stop.bat** 来停止服务器
4. **管理台无认证保护**，仅绑定本机使用，不要暴露到公网
5. **Chrome 工作区**必须正确配置为 Profile 4
