# 用户脚本排障

当前正式脚本是 [`scripts/userscript/学习通脚本.js`](../../scripts/userscript/学习通脚本.js)，显示名称为 `Chaoxing Toolkit Next｜学习通辅助与本地题库`。请先阅读 [安装与升级步骤](quick-start.md#用户脚本安装与升级)，避免同时运行多个版本。

## 脚本没有界面

1. 在 Tampermonkey 管理面板确认脚本已保存且启用；检查浏览器是否按扩展提示允许用户脚本运行。
2. 在课程页面的扩展菜单确认当前脚本处于运行状态。文件头部 `@match` 决定匹配范围，不匹配的页面不会加载。
3. 刷新页面；在开发者工具 Console 中查看是否有依赖加载或运行错误。界面入口只在对应页面及流程中出现，不保证每个学习通页面都显示全部按钮。
4. 暂时停用重复脚本和可能冲突的扩展后复验。不要通过删除脚本或清空存储作为第一步排查，否则可能丢失个人设置。

## 依赖加载报错

脚本通过 `@require` 和 `@resource` 加载 Vue、Pinia、Element Plus 等第三方资源。若出现 `Vue is not defined` 或网络错误，先检查具体依赖 URL 是否可访问，以及 Tampermonkey 的加载错误。

正式文件目前使用 jsDelivr。需要切换可信 CDN 时，保持完整依赖清单、版本、顺序及 `data:` 初始化行一致，仅替换确认不可访问的 URL；不要直接粘贴历史指南中的旧版头部，也不要使用来源不明的“修复脚本”。安装后重新保存并刷新。

## 本地题库连接失败

1. 打开 `http://localhost:8002/api/health`，先确认后端可用。
2. 核对题库总开关、自定义题库开关和接口地址 `http://localhost:8002/api/search`。
3. 修改端口后同步修改地址。自定义域名可能需要文件头部 `@connect` 权限和扩展的连接授权。
4. 结合日志区分网络失败、没有命中题库和成功返回答案；API 返回成功不意味着答案一定正确。

## 验证、卡顿和视频问题

检测到微信验证或图片验证码时，脚本会暂停相关自动任务并提示手动处理。完成验证后刷新页面，不通过复制网址、开新标签或其他方式尝试绕过验证。

章节轮询和视频播放仍依赖实际页面。避免同时在多个标签页自动处理同一课程，先停用脚本确认卡顿是否来自脚本，再提供可复现步骤。浏览器自动播放和后台节流也可能影响播放，随机暂停默认关闭；不同浏览器和平台更新后的行为需人工验证。

答案已选中但填答异常时，请说明题目类型、使用的答案表达、原选中状态和实际结果，使用自拟题目复现，不上传受保护试题。

## 提交反馈

向 [本仓库 Issues](https://github.com/jiahao07A/chaoxing-toolkit-next/issues) 提供脚本版本、浏览器/Tampermonkey 版本、复现步骤及脱敏日志。截图和 URL 应移除账号、课程访问参数、密钥、Cookies 与个人数据。安全问题使用 [安全报告方式](../../SECURITY.md#报告安全问题)。
