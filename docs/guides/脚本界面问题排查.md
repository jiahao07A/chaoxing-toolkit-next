# 脚本界面无法显示 - 解决方案

## 🔍 问题诊断

### 步骤 1: 检查 Tampermonkey 是否启用脚本

1. 点击浏览器工具栏的 **Tampermonkey 图标**（猴子图标）
2. 查看脚本列表中是否有：
   - **💯【超星学习通满分助手】**
3. 确认脚本状态：
   - ✅ 应该显示**绿色对勾**（已启用）
   - ❌ 如果是**红色叉号**（已禁用），点击启用

### 步骤 2: 检查脚本是否在当前页面生效

1. 在学习通页面，点击 Tampermonkey 图标
2. 应该看到：
   ```
   运行中的脚本：
   💯【超星学习通满分助手】
   ```
3. 如果没有显示，说明脚本没有在此页面运行

### 步骤 3: 强制刷新页面

按 **Ctrl + F5** 强制刷新页面（清除缓存）

### 步骤 4: 检查浏览器控制台

1. 按 **F12** 打开开发者工具
2. 切换到 **Console（控制台）** 标签
3. 查看是否有红色错误信息
4. 截图发给我，我可以帮您分析

## 🔧 解决方案

### 方案 1: 重新安装脚本

1. 打开 Tampermonkey 管理面板
2. 找到 **💯【超星学习通满分助手】**
3. 点击 **删除**
4. 重新打开 `scripts/userscript/学习通脚本.js` 文件
5. 复制全部内容
6. 在 Tampermonkey 中点击 **+** 创建新脚本
7. 粘贴内容并保存
8. 刷新学习通页面

### 方案 2: 检查脚本匹配规则

1. 打开 Tampermonkey 管理面板
2. 点击脚本名称进入编辑
3. 检查 `@match` 行：
   ```javascript
   // @match        *://*.chaoxing.com/*
   ```
4. 确保当前页面 URL 包含 `chaoxing.com`

### 方案 3: 手动添加权限

1. 编辑脚本
2. 确认以下行存在：
   ```javascript
   // @grant        GM_addStyle
   // @grant        GM_getResourceText
   // @grant        GM_getValue
   // @grant        GM_setValue
   // @grant        GM_xmlhttpRequest
   // @grant        unsafeWindow
   ```
3. 保存并刷新页面

### 方案 4: 清除 Tampermonkey 缓存

1. 打开 Tampermonkey 设置
2. 找到 **实用工具** 标签
3. 点击 **清除脚本存储**
4. 刷新页面

## 🤖 微信验证与章节页面卡顿

新版脚本不会自动复制课程网址、打开新标签或关闭当前页面。检测到学习通的微信验证弹窗或章节内图片验证码后，脚本只会提示用户手动完成验证，并暂停自动任务；验证完成后请手动刷新当前页面。

本仓库的正式脚本是 `scripts/userscript/学习通脚本.js`。它不再从原作者 GreasyFork 地址自动更新；本仓库发布修复后，需要手动将新版脚本安装到 Tampermonkey。

章节页面的后台检查间隔为约 5 秒，任务 iframe 尚未加载或任务数据异常时会等待下一轮重试。视频播放默认按 `1.5x`、自动播放、1 秒状态监控、7 秒无进度阈值、1.5 秒恢复冷却和 2 秒失败重试运行；首次播放先使用页面原本的声音状态，只有播放被拒绝时才立即静音回退，随后再按 2 秒间隔重试，最多 10 次。播放器同时支持 video.js 和原生 `video` 元素。随机暂停默认关闭，升级后首次读取旧配置时也会自动关闭一次。恢复播放请求带有冷却和失败退避，不会在 `waiting`/`pause` 事件密集出现时反复调用播放器；脚本不派发合成鼠标事件。脚本只在顶层页面运行验证检测，并在脚本实例替换或因验证停止时清理定时器和 MutationObserver，避免重复实例累积导致页面卡顿。

如果页面仍然卡住，请先手动刷新页面，再在控制台检查是否存在多个同名脚本实例或持续增长的错误日志；不要同时打开同一课程的多个自动处理标签页。

## 🔄 临时替代方案

如果脚本界面无法显示，您可以：

### 1. 使用浏览器控制台手动配置

按 F12，在控制台输入：

```javascript
// 启用自定义题库
GM_setValue('config', {
  ...GM_getValue('config'),
  customApiEnabled: true,
  customApiUrl: 'http://localhost:8002/api/search',
  customApiKey: '',
  autoAnswer: true,
  autoSubmit: true
});

// 刷新页面
location.reload();
```

### 2. 直接编辑脚本默认配置

1. 打开 Tampermonkey 编辑脚本
2. 找到 `defaultConfig$1` 部分
3. 修改：
   ```javascript
   customApiEnabled: true,
   customApiUrl: "http://localhost:8002/api/search",
   ```
4. 保存并刷新
